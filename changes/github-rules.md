### For developers

- **Rules on GitHub** (roadmap J1.2). A change reaches `main` through a pull request whose seven *Tests* jobs are
  green, `main` cannot be force-pushed or deleted, and a release tag `v…` is never moved or deleted. Repository admins
  may bypass both rules, so the owner's release order is unchanged. See *Rules on GitHub* in `docs/DEVELOPING.md`.
